# 焚决

创作技能扩展插件。需要神思 0.0.20 或更新版。

本仓库公开。神思插件广场中焚决标记为VIP插件，仅向有效会员、管理员及获授权账号展示；公开仓库的外部下载链接不受应用内会员权限限制。VIP显隐与授权需要新版账号服务，未部署时不能据此视为已在生产广场上线。

下载本仓库 Release 的 `.plugin.json` 文件，在神思「设置 → 扩展插件 → 从文件安装插件」中选择安装。无需勾选本地代码权限。启用后在对话 @ 技能的“焚决”目录中按中文名选择，普通对话会依据目录自动选择并读取相关技能。停用/卸载后不再调用，原知识库文件不受影响。技能说明、规则和路由按包内目录显示在知识库。

本包只含技能和参考文本，不含账号、密钥、普通笔记、视频或程序源码。技能使用现有模型配置与宿主能力，不能替代模型订阅、额度或平台授权。
